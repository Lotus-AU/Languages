# Languages
Translation files that Project Lotus uses.


## How to translate and add your own language!
Translations are managed through our [Weblate Instance](https://translate.lotusau.top/projects/lotuscontinued/). 

If you want to add a new Language or help translate an existing one, please reach out to us on our [Discord Server](https://discord.com/projectlotus) and we can help you get set up. Thanks!
